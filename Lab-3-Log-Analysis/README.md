# Cybersecurity Lab #3 - Python Log Analysis

## Overview
This project demonstrates basic cybersecurity log analysis using Python to identify suspicious failed login activity from authentication logs.

## Objective
Analyze authentication logs and detect repeated failed login attempts from suspicious IP addresses.

## Tools Used
- Python 3
- VS Code
- macOS Terminal
- Git / GitHub

## Skills Demonstrated
- Log analysis
- Python scripting
- Threat detection logic
- Security investigation workflow
- Basic automation

## Files
- `parser.py` → Python log parser
- `logs/auth.log` → sample authentication logs
- `report.md` → analysis findings
