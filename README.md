# Cybersecurity Reconnaissance Lab #1 - Network Scanning

## Overview
This project demonstrates foundational cybersecurity skills using network reconnaissance techniques to identify open ports, running services, and potential security risks on a test target.

## Objective
Perform structured reconnaissance on a public test host and document findings in a professional security report format.

## Tools Used
- Nmap
- macOS Terminal
- VS Code
- Git / GitHub

## Methodology
1. Conducted network scan using Nmap
2. Identified open ports and services
3. Analyzed potential security risks
4. Documented findings in structured report
5. Stored results in version-controlled GitHub repository

## Key Findings
- SSH (Port 22) exposed
- HTTP (Port 80) exposed
- Linux-based system detected
- Service versions revealed

## Skills Demonstrated
- Network reconnaissance
- Service enumeration
- Security analysis thinking
- Technical documentation
- Git version control workflow
